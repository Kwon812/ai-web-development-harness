# Context Harness

## 목적
평가 진행 중 문제, 데이터, 요구사항, 담당자 답변, 결정 및 진행 상태를 일관되게 유지한다.

## 규칙
- 문제·데이터·요구사항을 받으면 즉시 분석한다. 시작 전에 상태 파일이나 결정 로그를 만들지 않는다.
- 질문 ID와 담당자 답변을 연결하고 확정/미확정 내용을 구분한다.
- 답변으로 요구사항이 변경되면 구현 영향, 테스트 기준, 승인 필요 여부를 기록한다.
- 현재 Phase, 기능, 승인 여부와 미해결 사항을 대화와 작업 맥락에서 관리한다.
- 사용자가 요청하거나 맥락 유지에 실제 필요할 때만 별도 문서를 생성한다.
- 사용자 승인 없이 다음 기능이나 Phase로 넘어가지 않는다.
