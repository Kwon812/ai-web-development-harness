# Context Harness

## 목적
대화가 길어져도 요구사항, 결정, 진행 상태와 미해결 사항을 일관되게 유지한다.

## 관리 문서
- `docs/PROJECT-STATE.md`: 현재 Phase, 기능, 상태, 기술 스택, 다음 작업
- `docs/DECISION-LOG.md`: 결정 사항, 근거, 승인자, 날짜
- 요구사항 및 설계 문서: 변경 시 버전과 변경 이유 기록

## 규칙
새 작업 전 관련 문서를 확인한다. 결정이 바뀌면 이전 기록을 삭제하지 말고 변경 이력을 남긴다. 추정과 확정 사실을 구분한다. 컨텍스트가 불완전하면 사용자에게 확인한다.
