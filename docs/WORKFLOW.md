# 개발 워크플로

## 1. 착수
문제와 목표를 분석하고 사용자, 제약, 성공 기준을 확인한다.

## 2. 기획
서비스 범위, 사용자 시나리오, 기능 목록과 수용 기준을 작성한다.

## 3. 기술 결정
기술 후보를 비교하고 비용·운영·보안·유지보수 근거를 제시한다. 사용자 승인 후 확정한다.

## 4. 설계 및 Phase 계획
화면, API, 데이터, 아키텍처를 설계하고 Phase와 기능 단위로 나눈다. 계획 승인을 받는다.

## 5. 기능 단위 반복
기능 계획 → 구현 → 테스트 → 구현 보고서 → 사용자 승인 순서로 진행한다. 승인 전 다음 기능을 시작하지 않는다.

## 6. Phase 종료
Phase 범위의 통합 검증, 잔여 결함, 변경 파일, 미해결 사항을 종합 보고하고 승인받는다.

## 7. 완료
배포·운영 문서와 최종 결과를 정리한다. 배포나 운영 데이터 변경은 별도 승인 대상이다.
