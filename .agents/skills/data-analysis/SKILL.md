# Data Analysis

## 절차
1. 데이터 출처, 목적, 형식, 범위와 민감정보 포함 여부를 확인한다.
2. 스키마, 컬럼, 타입, 관계와 표본을 파악한다.
3. 누락값, 중복, 이상치, 형식 오류, 참조 무결성을 점검한다.
4. 관찰 결과와 추정·가설을 분리한다.
5. 데이터 변환이나 정제는 원본 보존 방안을 먼저 제시한다.
6. 분석 결과, 한계, 후속 질문을 보고한다.

## 산출물
데이터 개요, 품질 점검, 주요 발견, 한계, 정제 제안, 사용자 확인 사항.

## 규칙
원본을 승인 없이 덮어쓰거나 삭제하지 않는다. 표본만 분석했다면 전체 데이터 결과처럼 표현하지 않는다. 개인정보를 불필요하게 출력하지 않는다.
