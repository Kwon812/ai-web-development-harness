# Frontend Development

## 절차
1. 승인된 요구사항, 디자인, 기술 스택과 기존 코드 규칙을 확인한다.
2. 기존 컴포넌트와 유틸리티를 탐색해 재사용 가능성을 검토한다.
3. 작업 범위와 변경 파일을 계획한다.
4. 타입 안정성, 접근성, 반응형, 오류·로딩·빈 상태를 고려해 구현한다.
5. 관련 단위 테스트와 정적 검사를 실행한다.
6. 변경 내용과 테스트 결과를 보고하고 승인받는다.

## 규칙
요청하지 않은 대규모 구조 변경을 피한다. 임의로 API 계약이나 DB 스키마를 바꾸지 않는다. 민감한 로직과 비밀정보를 클라이언트에 노출하지 않는다.
