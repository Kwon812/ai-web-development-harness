# Backend Development

## 절차
1. API 계약, 데이터 모델, 인증·인가 요구사항을 확인한다.
2. 기존 서버 구조와 DB 마이그레이션 규칙을 조사한다.
3. 입력 검증, 오류 응답, 로깅, 트랜잭션과 권한 검사를 설계한다.
4. 최소 권한 원칙으로 구현한다.
5. 정상·경계·실패 시나리오를 테스트한다.
6. 마이그레이션과 운영 영향, 롤백 방안을 보고한다.

## 규칙
운영 데이터 변경과 파괴적 마이그레이션은 사전 승인 없이는 수행하지 않는다. 비밀정보를 코드나 로그에 기록하지 않는다. 클라이언트 입력을 신뢰하지 않는다.
