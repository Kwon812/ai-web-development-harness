# UI UX Design

## 절차
1. 승인된 요구사항과 사용자 시나리오를 확인한다.
2. 정보 구조와 내비게이션을 설계한다.
3. 페이지별 목적, 주요 정보, 행동 요소를 정의한다.
4. 주요 상태(로딩, 빈 화면, 오류, 성공, 권한 없음)를 설계한다.
5. 모바일·태블릿·데스크톱 반응형 동작을 정의한다.
6. 접근성, 키보드 조작, 가독성을 검토한다.
7. 구현 전 설계안과 결정 필요 사항을 보고한다.

## 산출물
사이트맵, 페이지 명세, 사용자 흐름, 컴포넌트 목록, 상태 정의, 반응형·접근성 기준.

## 규칙
시각적 장식보다 사용 목적과 흐름을 우선한다. 승인된 디자인 시스템이 있으면 재사용한다.
