# Stakeholder Communication

## 절차
1. 현재까지 확인된 사실과 미확정 사항을 분리한다.
2. 구현에 영향을 주는 질문을 우선순위화한다.
3. 질문마다 배경, 선택지(가능한 경우), 기본 영향, 답변이 필요한 시점을 적는다.
4. 수신자가 바로 답할 수 있는 간결한 문장으로 작성한다.
5. 답변을 받으면 결정 로그에 기록하고 관련 요구사항을 갱신한다.

## 산출물
질문 목록, 확인 목적, 답변 선택지, 미응답 시 영향, 결정 기록 초안.

## 규칙
담당자의 답변을 대신 만들어내지 않는다. 미응답 상태를 승인으로 간주하지 않는다. 여러 독립 결정을 하나의 모호한 질문으로 합치지 않는다.
