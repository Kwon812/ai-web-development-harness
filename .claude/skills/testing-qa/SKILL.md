# Testing QA

## 절차
1. 요구사항과 수용 기준에서 테스트 항목을 도출한다.
2. 정상, 경계, 예외, 권한, 보안 시나리오를 포함한다.
3. 기존 테스트와 실행 방법을 확인한다.
4. 테스트를 실행하고 실제 명령과 결과를 기록한다.
5. 실패는 재현 조건, 원인, 영향 범위를 분석한다.
6. 수정 후 관련 테스트와 회귀 테스트를 재실행한다.
7. 통과·실패·미실행 항목을 구분해 보고한다.

## 산출물
테스트 계획, 케이스, 실행 로그 요약, 결함 목록, 잔여 위험.

## 규칙
실행하지 않은 테스트를 통과로 기록하지 않는다. 실패를 숨기지 않는다. 외부 서비스 의존으로 검증하지 못한 항목은 한계를 명시한다.
